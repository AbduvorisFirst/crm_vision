# BrainCam AI — "Make Every Camera Intelligent"

Платформа интеллектуальной видео- и аудио-аналитики для ритейла, магазинов, кафе и ресторанов на базе обычных IP-камер.

---

## 🌟 Основные возможности MVP

1. **Telegram Bot для продавца и владельца бизнеса:**
   * Двуязычный интерфейс: **Русский 🇷🇺** и **Узбекский 🇺🇿** (переключается в 1 клик).
   * Ежедневная вечерняя сводка:
     - 👥 **Трафик:** Сколько посетителей зашло за день
     - 🛍 **Покупки:** Сколько человек совершили покупку на кассе
     - 📈 **Конверсия:** Процент покупок от общего трафика
     - ⏰ **Пиковый час:** Самое загруженное время
     - 👔 **Оценка персонала:** AI-контроль присутствия и активности сотрудников
     - 🎙 **Жалобы:** Количество зафиксированных аудио-жалоб клиентов
     - 💡 **AI-рекомендации:** Советы BrainCam AI по увеличению выручки и устранению очередей.
   * Моментальный анализ кадра / фото / видео: прямо в чате Telegram.
   * Проверка связи с камерами и запрос живого снимка.

2. **AI Модель — Google Gemini (gemini-2.5-flash-lite):**
   * Самая быстрая и доступная мультимодальная модель от Google.
   * Компьютерное зрение: подсчет людей, фиксация покупок на кассе, детекция очередей.
   * Аудио-аналитика: распознавание речи с микрофона камеры, выявление жалоб, конфликтов, вежливости персонала.

3. **Merchant Web Dashboard (Веб-панель продавца):**
   * Интерактивные карточки KPI в реальном времени.
   * График почасового трафика и покупок (Chart.js).
   * Управление камерами и зонами (Вход, Касса, Зал).
   * Журнал аудио-инцидентов и жалоб покупателей.
   * Инструменты массовой интеграции.

4. **Массовая интеграция камер (Mass Onboarding):**
   * **Автоматическое сканирование локальной сети (Subnet Scanner):** находит все камеры с открытыми RTSP/ONVIF портами (554, 8554, 8000) в диапазоне `192.168.x.x`.
   * **Пакетная загрузка через CSV:** импорт сотен камер одним файлом (готовый шаблон включен).
   * **Local Edge Agent (`edge_agent/braincam_agent.py`):** легкий скрипт для магазинов с серыми IP-адресами (пробрасывает потоки на сервер BrainCam AI).

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
# Активация виртуального окружения (Python 3.12)
.\.venv\Scripts\activate

# Установка пакетов
pip install -r requirements.txt
```

### 2. Настройка конфигурации (.env)
Скопируйте пример:
```bash
copy .env.example .env
```
Заполните параметры:
* `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather)
* `GEMINI_API_KEY` — ключ API из [Google AI Studio](https://aistudio.google.com/)
* `GEMINI_MODEL=gemini-2.5-flash-lite`

### 3. Запуск сервиса (Web Dashboard + Telegram Bot)
```bash
python main.py
```
После запуска:
* **Веб-дашборд доступен по адресу:** `http://localhost:8000`
* **Telegram-бот:** активен и принимает команды (`/start`, `/report`, `/cameras`, отправку фото и голосовых сообщений).

```
├── braincam/
│   ├── ai/
│   │   └── gemini_service.py       # Мультимодальный AI (Gemini 2.5 Flash Lite)
│   ├── bot/
│   │   ├── keyboards.py            # Меню и кнопки Telegram (RU/UZ)
│   │   └── main_bot.py             # Обработчики Telegram Bot (Aiogram 3)
│   ├── db/
│   │   ├── models.py               # Модели SQLAlchemy (Org, User, Camera, Event, Report)
│   │   └── session.py              # Асинхронное подключение к БД
│   ├── services/
│   │   ├── analytics_service.py    # Подсчет конверсии, трафика, агрегаты
│   │   └── notification_service.py # Форматирование отчетов (RU & UZ)
│   ├── video/
│   │   ├── rtsp_capture.py         # Захват кадров с RTSP / Pillow / OpenCV
│   │   └── mass_scanner.py         # Сетевой сканер подсетей и парсер CSV
│   └── web/
│       ├── app.py                  # FastAPI сервер и REST API
│       └── templates/
│           └── dashboard.html      # Полнофункциональный дашборд продавца
├── edge_agent/
│   └── braincam_agent.py           # Локальный агент для клиентских сетей
├── tests/
│   └── test_braincam.py            # Автоматические тесты
├── main.py                         # Единая точка запуска
├── requirements.txt                # Зависимости ядра
└── .env.example                    # Шаблон переменных окружения
```
