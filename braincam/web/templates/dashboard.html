Подключение без белого IP: Пошаговое руководство Local Edge Agent

Решает проблему закрытой локальной сети (192.168.x.x). Агент работает на ПК кассира, сервере магазина или мини-ПК.

Скачать agent.py
1 Скачать скрипт
curl -O http://localhost:8000/edge_agent/braincam_agent.py

Или нажмите кнопку «Скачать agent.py» и положите файл в любую папку.

2 Установить зависимости
pip install opencv-python requests

Требуется Python 3.8+ на кассовом компьютере (Windows, Linux, macOS).

3 Запустить агент
python braincam_agent.py --server http://localhost:8000 --camera-id 1 --rtsp "rtsp://admin:pass@192.168.1.64:554/Streaming/Channels/102"

Агент каждые 1.0 сек передает кадры и статус online в облако.

Автозапуск при старте Windows / Linux: В Windows добавьте ярлык в shell:startup или создайте задачу в Планировщике. В Linux используйте systemd сервис.
